# 🍦 Ice Cream Revenue Prediction using Linear Regression

## 📌 Project Overview
This project predicts **ice cream sales revenue** based on **temperature** using a Machine Learning approach.  
A **Linear Regression model** is implemented to analyze the relationship between temperature and revenue and to make future predictions.

The project demonstrates fundamental concepts of:
- Data analysis
- Data visualization
- Machine Learning model training
- Prediction using regression algorithms

---

## 🎯 Problem Statement
Ice cream sales are highly influenced by weather conditions, especially temperature.  
The objective of this project is to build a predictive model that estimates **revenue generated from ice cream sales** based on temperature values.

---

## 🧠 Model Used
- **Linear Regression**
- Supervised Machine Learning Algorithm

The model learns the relationship between:
- **Independent Variable:** Temperature (°C)
- **Dependent Variable:** Revenue

## 📊 Project Workflow
1. Data Creation & Loading

   - Correlation Heatmap
4. Data Splitting (Train/Test)

6. Prediction on Test Data
